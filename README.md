## The review

> One star. He types on MY keyboard all day, then has the nerve to close the laptop on my tail. I left a hairball in his shoe. Fair trade.

## How it works

`main.ts` (Node 22+) writes one funny single-line one-star review, written by a
house cat about its human, to `/output/entry.txt`. The program validates the
line first: it must be 1–200 characters, a single line, and not blank.

```sh
node main.ts
```
